# Mark Six Smart Picks｜六合彩聰明組合

一個以繁體中文呈現的六合彩號碼組合工具。自訂輸出注數，平均分配 1–49 號的出現次數，並可查看頻率、複製結果及匯出 CSV。

採用藍色日間／夜間主題，支援電腦及手機。整個網站由單一 `index.html` 組成，無需安裝套件或設定後端。

## 功能

| 功能 | 說明 |
| --- | --- |
| 自訂注數 | 每次產生 1–1,000 注，另設常用注數快捷按鈕。 |
| 不重複組合 | 每注包含 6 個不同號碼，按由小至大排列；同一次輸出不會出現完全相同的組合。 |
| 平均分配 | 1–49 號的出現次數最多相差 1 次，包括尚未出現的號碼。 |
| 出現頻率 | 顯示全部結果中各號碼的次數，支援按號碼或次數排序。 |
| 結果分頁 | 可選擇每頁顯示 10、25、50 或 100 注。 |
| 複製結果 | 複製全部組合，使用定位字元分隔欄位，可貼入試算表。 |
| CSV 匯出 | 匯出全部組合，使用 UTF-8 BOM 編碼及 CRLF 換行。 |
| 日／夜主題 | 首次開啟跟隨系統設定；手動切換後，在瀏覽器允許儲存時記住偏好。 |

## 使用方法

1. 用瀏覽器開啟 `index.html`，或進入已部署的網站。
2. 輸入需要的注數，或使用快捷按鈕。
3. 按 **產生組合**，查看結果及出現頻率。
4. 按 **複製結果** 或 **匯出 CSV**，取得全部資料。
5. 如需重新開始，按 **清除結果**。

修改注數後，需要再次按「產生組合」才會更新結果。每次產生的新結果會取代上一次結果；切換主題、排序或分頁不會重新產生號碼。

匯出與複製均包含本次全部組合，不受目前分頁影響。組合結果只保留於目前頁面，重新整理或關閉前，可先匯出需要保存的資料。

## 平均分配方式

產生每一注時，優先選取目前出現次數較少的號碼；次數相同時隨機決定順序。完成後，每個號碼的次數為「總注數 × 6 ÷ 49」向下或向上取整數，因此最多相差 1 次。

| 輸出注數 | 號碼位置總數 | 最終分布 |
| --- | --- | --- |
| 8 注 | 48 | 48 個號碼各出現 1 次，1 個號碼未出現。 |
| 49 注 | 294 | 全部 49 個號碼各出現 6 次。 |
| 50 注 | 300 | 43 個號碼各出現 6 次，6 個號碼各出現 7 次。 |

「出現頻率」統計的是本次產生的組合，並非歷史開獎資料。不同次產生的結果之間，可能出現相同組合。

## CSV 格式

固定使用以下七個欄位：

```csv
注數,N1,N2,N3,N4,N5,N6
1,2,9,16,24,35,47
2,4,11,18,27,38,49
3,6,13,20,29,40,45
4,1,8,15,22,33,42
5,3,10,17,26,36,48
```

以上為格式示例。第一欄是組合編號，後六欄是號碼；CSV 使用整數，不保留畫面上的前置零。檔名會包含輸出注數及匯出時間，可使用 Excel 或其他試算表軟體開啟。

## 部署到 GitHub Pages

將以下檔案上載到儲存庫最外層：

```text
marksix-smart-picks/
├── index.html
└── README.md
```

1. 建立公開儲存庫 `marksix-smart-picks`。
2. 將 `index.html` 與 `README.md` 上載至 `main` 分支並提交。
3. 開啟儲存庫的 **Settings → Pages**。
4. 將 **Source** 設為 **Deploy from a branch**。
5. 選擇 **main** 分支及 **/ (root)** 資料夾，按 **Save**。
6. 等待部署完成，再使用 Pages 設定頁提供的網址開啟網站。

以 `bbeennhk/marksix-smart-picks` 為例，部署完成後的網址為：

[https://bbeennhk.github.io/marksix-smart-picks/](https://bbeennhk.github.io/marksix-smart-picks/)

之後更新 `main` 分支的 `index.html`，GitHub Pages 會重新部署網站。詳細設定可參考 [GitHub Pages 官方說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 技術與資料儲存

- 使用原生 HTML、CSS 與 JavaScript，沒有外部套件、字型或 API 依賴。
- 號碼產生、頻率計算及檔案匯出均在瀏覽器內執行。
- 瀏覽器支援時使用 Web Crypto 取得隨機數，否則使用 `Math.random()`。
- `localStorage` 僅用於記住日／夜主題，不儲存組合結果。
- 直接下載 `index.html` 後可離線使用；需要啟用 JavaScript。
- 如果瀏覽器不允許複製到剪貼簿，可改用 CSV 匯出。
